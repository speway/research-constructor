# Чек-лист качества

## Научная логика

- [x] Психологическая проблема, объект, предмет, вопрос, цель и гипотезы разведены по смыслу.
- [x] Теория, предполагаемый механизм, операционализация и показатель образуют проверяемую цепочку.
- [x] Локальный профиль филиала проверяет тему, задачи, структуру введения, эмпирической главы и выводов.
- [x] Дизайн явно ограничивает допустимую интерпретацию.
- [x] Для эксперимента предусмотрены манипуляция, распределение, ослепление, проверка воздействия и карта артефактов.
- [x] Выборка включает границы совокупности, критерии, стратегию набора и отсев.
- [x] Методы проверяются по теории, адаптации, психометрике, лицензии и нагрузке.
- [x] Анализ фиксирует единицу анализа, первичный исход, зависимость наблюдений, предпосылки, эффект, интервал, множественность и пропуски.
- [x] Нормальность не используется как единственный автоматический переключатель метода.
- [x] Этика включает риски, согласие, минимизацию данных, доступ, срок, удаление и инциденты.
- [x] Аудит проверяет связность, а не выдаёт ложную оценку научной истины.

## Продукт

- [x] Двенадцать разделов образуют последовательный маршрут.
- [x] Пять типов исследования поддерживаются содержательно.
- [x] Справочник объединяет термины, методы, стандарты, требования филиала и экспериментальные угрозы.
- [x] Прогресс рассчитывается по 35 содержательным критериям.
- [x] Проект автоматически сохраняется только в браузере.
- [x] JSON-импорт ограничен по размеру, проходит белый список полей и нормализацию ссылок.
- [x] Очистка удаляет текущий и прежний ключи приложения, проверяет результат и не затрагивает чужое хранилище.
- [x] Есть JSON-резервная копия и структурированный DOCX-экспорт.
- [x] Есть генератор черновика информированного согласия.
- [x] Нет загрузки сырых таблиц и данных участников.

## Интерфейс и техника

- [x] Семантические поля, подписи и состояния фокуса доступны клавиатуре.
- [x] Есть режим reduced motion и адаптивные сетки.
- [x] Нет горизонтального переполнения на проверенном desktop-предпросмотре.
- [x] Линтер, Vinext/Sites build, Next.js production build и server-render tests проходят.
- [x] Автотесты проверяют полное и изолированное удаление данных.
- [x] В браузере проверены профиль филиала, 13 угроз эксперимента, 6 стадий анализа и справочник.
- [x] Production проверен после публикации на стабильном Vercel-адресе.

## Перед реальным исследованием

- [ ] Сверить профиль с актуальным регламентом кафедры и письменными указаниями руководителя.
- [ ] Получить проверку и одобрение научного руководителя для всех формулировок и решений.
- [ ] Выполнить точный расчёт объёма под основной анализ и дизайн.
- [ ] Проверить права, адаптации и психометрические свойства конкретных версий методик.
- [ ] Подготовить отдельное защищённое хранилище и процедуру удаления реальных данных.
- [ ] Получить этическое одобрение, если оно требуется организацией.
