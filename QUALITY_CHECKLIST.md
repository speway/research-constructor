# Чек-лист качества

## Научная логика

- [x] Тема, проблема, объект, предмет, вопрос, цель и гипотезы разведены по смыслу.
- [x] Дизайн ограничивает допустимую интерпретацию результатов.
- [x] Выборка включает границы совокупности, критерии и стратегию набора.
- [x] Методы проверяются по адаптации, психометрике и условиям использования.
- [x] Анализ фиксирует первичный исход, предпосылки, эффект и пропуски.
- [x] Этика включает риски, отказ, согласие и жизненный цикл данных.
- [x] Аудит проверяет связность, а не выдаёт ложную оценку научного качества.
- [x] Стресс-рецензия требует зафиксировать опровержение, альтернативы и границы переноса, а не просто поставить галочки.

## Продукт

- [x] Четыре смысловых этапа объединяют 12 рабочих блоков.
- [x] Прогресс пересчитывается из содержательных критериев.
- [x] Проект автоматически сохраняется только в браузере.
- [x] Есть полная и безопасная JSON-копии, проверяемый импорт и DOCX-экспорт.
- [x] Приватная сессия удаляет локальные ключи и отключает автосохранение.
- [x] Экран-щит мгновенно скрывает содержание проекта.
- [x] Импорт отклоняет подозрительные массивы данных участников и слишком сложные структуры.
- [x] Есть генератор черновика информированного согласия.
- [x] Есть ориентир выборки с явным предупреждением об ограничениях.
- [x] Интерфейс прямо запрещает ввод персональных данных участников и классифицирует чувствительность.
- [x] Есть быстрые сценарии, исследовательская дека и три следующих действия без тупикового экрана.
- [x] Есть отмена/возврат действий; при очистке история в памяти также уничтожается.
- [x] Импорт ограничивает длину строк, диапазоны чисел, глубину, ширину, циклы и неизвестные ответы стресс-рецензии.

## Интерфейс и техника

- [x] Семантические поля и подписи доступны клавиатуре.
- [x] Есть состояния фокуса и режим reduced motion.
- [x] Сетка адаптируется на 1180, 820 и 580 px.
- [x] Линтер, production build и server-render tests проходят.
- [x] Проверены переходы, мгновенный разбор темы, cockpit, экран-щит, импорт и удаление.
- [x] 11 автоматических тестов проходят, включая 2000 fuzz-импортов и ввод более миллиона символов.
- [x] SSR не теряет быстрый старт, следующие действия, командный переход и стресс-рецензию.
- [x] Метаданные, язык страницы и favicon заданы.

## Перед реальным исследованием

- [ ] Сверить работу с актуальным регламентом конкретной кафедры.
- [ ] Обсудить проект и границы вывода с научным руководителем.
- [ ] Выполнить точный расчёт мощности под основной тест.
- [ ] Проверить права и русскоязычные адаптации методик.
- [ ] Получить этическое одобрение, если оно требуется организацией.
