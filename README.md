# Конструктор исследования

Интерактивная рабочая среда для проектирования психологического исследования: от замысла и теории до дизайна, эксперимента, анализа, этики данных и аудита связности.

[Открыть сайт](https://research-constructor.vercel.app) · [Резервная публикация](https://research-constructor.dukallis-dristallis7.chatgpt.site)

## Возможности

- 4 смысловых этапа и 12 рабочих блоков;
- 5 быстрых сценариев для старта: связи, эксперимент, качественное, смешанное и лонгитюдное исследование;
- исследовательская дека: здоровье каждого этапа, три следующих действия и живой бриф;
- исследовательский радар: цепочка «вопрос → механизм → основания → измерение → проверка → вывод»;
- рабочая матрица литературы с выводом, ограничением, ролью источника и контролем контраргументов;
- полевой стресс-симулятор: отсев, непригодные наблюдения, темп набора, приглашения, сроки и нагрузка;
- журнал решений с фиксацией изменений до и после просмотра данных;
- командный поиск по разделам и действиям (`Ctrl/⌘ K`), отмена и возврат изменений;
- универсальный, учебный (ТФ МГУ) и журнальный профили проверки;
- мгновенный разбор темы и живая карта «проблема → вопрос → механизм → проверка»;
- теоретическая мастерская с психологическими рамками школы МГУ и современными подходами;
- выбор дизайна и явные границы допустимых выводов;
- экспериментальный cockpit: 7 структур, 13 угроз валидности и индикатор готовности причинной проверки;
- конструктор выборки и ориентир её объёма;
- банк из 48+ методов с оценкой нагрузки, адаптации, лицензии и ограничений;
- справочник из 70+ терминов и 15 стандартов отчётности;
- карта выбора анализа, эффектов, предпосылок и робастных альтернатив;
- этический чек-лист, классификация чувствительности и черновик согласия;
- локальное автосохранение, приватная сессия, экран-щит, безопасный JSON и DOCX;
- блокировка подозрительного импорта наборов данных участников;
- блокировка импортов с повторяющимися e-mail/телефонными идентификаторами и ограничение сложности структуры;
- аудит по 35 содержательным контрольным точкам;
- стресс-рецензия по 8 критическим линзам: фальсификация, валидность, альтернативы, ошибки измерения, устойчивость анализа, этика, переносимость и реализуемость.

## Запуск

```bash
npm install
npm run dev
```

Проверка: `npm run lint`, `npm run typecheck`, `npm test`. Тестовый контур включает production build, строгую TypeScript-проверку, всплеск из 150 одновременных SSR-запросов, сверхдлинный ввод, циклические/широкие структуры, 10 000 fuzz-импортов и 20 000 стресс-сценариев набора. Для стандартной Next.js-сборки: `npx next build`.

Проект не предназначен для хранения персональных данных участников и не заменяет требования кафедры, консультацию научного руководителя или решение этического комитета.
