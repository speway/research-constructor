# Конструктор исследования

Научная рабочая среда для проектирования психологического исследования: от проблемы, предмета и теоретического механизма до дизайна, анализа, этики, отчёта и аудита связности.

[Открыть production](https://research-constructor.vercel.app) · [Резервная публикация](https://research-constructor.dukallis-dristallis7.chatgpt.site)

## Научная основа

Проект ориентирован на психологическую методологию и традиции факультета психологии МГУ: содержательное определение предмета, связь теории и эмпирической проверки, анализ психологических механизмов, деятельности и развития. Встроен локальный профиль кафедры психологии филиала МГУ в Ташкенте по протоколу № 3 от 28.09.2023 и рабочему плану эмпирической части 2025 года.

Регламент кафедры и решение научного руководителя всегда имеют приоритет.

## Возможности

- 12 связанных блоков: паспорт, логика, литература, переменные, дизайн, выборка, методы, протокол, анализ, этика, отчёт и аудит;
- пять маршрутов: количественный, качественный, смешанный, обзорный и психометрический;
- банк из 34 опросных, экспериментальных, качественных, наблюдательных и психофизиологических методов;
- справочник из 46 терминов, стандартов отчётности, локальных требований и угроз валидности;
- экспериментальный «кокпит»: манипуляция, распределение, ослепление, проверка воздействия и 13 источников артефактов;
- усиленная логика StatLab: шкала исхода, зависимость наблюдений, число условий, предпосылки, робастный вариант, эффект и интервал;
- точные проверки темы, объекта/предмета, задач, гипотез, причинного языка и связности анализа;
- структура эмпирической главы и правила интерпретации результатов по требованиям филиала;
- локальное автосохранение, безопасный JSON-импорт, DOCX-экспорт и проверяемое удаление текущего и прежнего ключей проекта;
- 35 контрольных точек аудита и автоматические предупреждения о методологических противоречиях.

## Приватность

Конструктор не предназначен для данных участников и не содержит загрузки исследовательских таблиц. Не вводите ФИО, контакты, ответы, идентификаторы, медицинские сведения или выгрузки. План проекта хранится только в `localStorage` текущего браузера; очистка удаляет только ключи приложения и проверяет их отсутствие.

## Запуск и проверка

```bash
npm install
npm run dev
```

```bash
npm run lint
npm test
npx next build
```

Тесты проверяют серверный рендеринг основного маршрута и полное, изолированное удаление локальных данных проекта.

## Важно

Запрещено основывать работу на заметках, формулировках и решениях конструктора или использовать их без проверки и одобрения научного руководителя. Конструктор не заменяет актуальный регламент кафедры, консультацию руководителя, проверку лицензий методик или решение этического комитета.
